# 1813 · ventetiden

Prototype af en venteskærm til Akuttelefonen 1813. Semesterprojekt, Advanced Design Processes, ITU efterår 2026 (gruppe 10). Ikke Region Hovedstadens app.

Bygget i p5.js. Råd fra akut.dk (Region Hovedstadens Akutberedskab). Musik fra Pixabay: "Golden Sunset Piano Music" (clavier-music) og "Radiant Mindfulness" (BreakzStudios).
